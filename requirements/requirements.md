## 작성 가이드

1. 어떤 사용자의 어떤 문제를 해결하는지 먼저 작성합니다.
2. 기능은 사용자 종류별로 나누어 작성합니다.
3. “빠르게”보다는 “3초 이내”처럼 확인 가능한 표현을 사용합니다.
4. 이번에 반드시 만들 기능은 `MVP 개발 범위`에 다시 정리합니다.
5. 만들지 않을 기능이나 기술적 제한은 [`constraints.md`](constraints.md)에 적습니다.
